这个站是什么

青榜是面向年满 18 周岁成年人的情趣用品公开销售榜，部署在 GitHub Pages 上，是静态页面。没有注册、没有购物车、没有支付，也不发货。

商品按钮会离开本站，打开商家自己的页面。那些网站如何处理数据，以它们的隐私政策为准。

年龄确认和语言

进入前需要确认已满 18 周岁。选择保存在你自己的浏览器 localStorage，键名是 qbt-age。语言选择保存在 qbt-lang。

这两项不上传到青榜的服务器。本站没有自有后端，也没有按姓名检索的用户档案。

统计

页面使用 Google Analytics 4，衡量 ID 是 G-1SF9TQS3F1。它可能通过 Cookie 记录页面浏览、大致地区、设备和引荐来源，用来了解哪些榜单被打开。

我们不用这份统计出售广告画像，也不把访客名单交给商家。你可以在浏览器里限制第三方 Cookie，或使用拦截 Google Analytics 的插件。

不出售个人数据

不出售、不交换、不出租个人数据。没有会员名单，也没有结账信息可以出售。

外链

商品链接指向 Amazon、品牌官网或香港网店，并使用 nofollow。点出去之后的 Cookie、账号和订单属于那个网站。

成人内容

页面只面向 18 周岁以上。不要把本站提交给未成年人。内容不是医疗或健康建议。

更正

静态站点无法按姓名删除一份不存在的用户档案。若要更正某一期的商品信息，或询问这份政策，请使用联系页里的 GitHub Issues。
