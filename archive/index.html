怎么读

日榜文件名是上海时间的日期。周榜文件名是 ISO 周，周一到周日。若周榜 JSON 带有 seed，那一页会写明它是某一天日榜的副本。若写明由多份日榜汇总，就不是 seed。

仅供年满 18 周岁的成年人浏览。

来源以每期 JSON 为准。设计上包括淘宝 / 天猫、Amazon 和独立品牌店。淘宝 / 天猫若仍在 sources_skipped，榜上就没有淘宝商品。

更新频率：日榜按上海时间每天整份更新；周榜在同一 ISO 周有两份或更多日榜时由日榜汇总，只有一份日榜时可能仍是带 seed 的副本。

本页是各平台公开热销榜的整理快照，不是医疗或健康建议，也不代表推荐购买。价格、库存和名次都会变，下单前请回到商家页面核对。

外链使用 nofollow。数据时区 Asia/Shanghai。
