怎么整理这份榜 · 仅限 18 周岁以上

数据方法

每一期榜单只使用当时能打开的公开页面。没有为了凑满 20 名编造商品，也没有把别的日期的数据混进来。

数据来源

榜单设计上会看三类公开页面：淘宝 / 天猫、Amazon，以及独立品牌或地区店铺。目前出现过的独立店和地区店有 Dame、Lovense、We-Vibe、Womanizer，以及香港 Waddy、SISTALK、Les'Play 与 Sex Concept。

某一期实际收录谁，以该期 JSON 的 sources_included 为准。没请求或打不开的来源写在 sources_skipped，不会用其他数据填补。

2026-10-16 在当天较早的抓取之后，又并入了三家公开页面能直接读到商品链接、名称和港币价格的香港店：SISTALK 的热卖分类、Les'Play 的畅销分类、Sex Concept 的畅销分类。名次是该页从上到下的顺序，每个来源最多 6 款，再按原有规则重排前 20。淘宝 / 天猫同日打开的是要靠 JavaScript 的搜索壳，静态 HTML 里没有商品链接和价格，sources_skipped 记为 blocked，没有编造商品。空的占位结构在 data/sources/taobao_tmall.placeholder.json。18 Gifts 的月销量页被 Cloudflare 拦住。LELO 的 /best-sellers 返回 404。MysteryVibe 没有重试（2026-10-15 是 HTTP 429）。PChome 24h 返回过页面，但不是可以确认的热销榜，所以没有并入。

更新频率

日榜按 Asia/Shanghai 的自然日更新。例行发布会整份覆盖 data/daily-latest.json，并把同一份文件写到 data/daily-YYYY-MM-DD.json 和 data/archive/daily/YYYY-MM-DD.json。不与旧条目合并。

周榜按 Asia/Shanghai 的周一至周日（ISO 周）更新。例行发布会整份覆盖 data/weekly-latest.json，并写入 data/archive/weekly/YYYY-Www.json。

日榜文件在 2026-10-16T10:59:47+08:00 形成第一版，同日 2026-10-16T17:03:22+08:00 并入香港店后重写。页面上的价格和名次对得上文件里的日期，不是打开页面这一刻的实时库存。

周榜不会停在“把某一天复制成一周”当作最终做法。scripts/build_weekly.py 查看 data/archive/daily/。同一个 ISO 周（上海时间，周一至周日）若有两份或更多日榜，就按商品链接去重，用出现天数、平均店内名次和最好店内名次汇总，写下 data/weekly-latest.json 和 data/archive/weekly/YYYY-Www.json，并且不写 seed。2026-W42 使用了 2026-10-15、2026-10-16、2026-10-17 与 2026-10-18，所以是汇总，不是副本。若某一周只有一份日榜，脚本不改写已有周榜；那种文件若仍带 seed，页面会写明它是那天日榜的副本。

排名规则

综合榜先按商品链接去重，每个来源最多留下 6 款，再排序：该店自己的名次从小到大，然后评分从高到低（没有评分的靠后），然后评价数量从高到低（没有条数的靠后），然后平台 id、商品名。最后取前 20 名。

这条规则也写在数据文件的 sort_rule 字段：dedupe by product_url; cap 6 per source; sort by source rank ASC, then rating DESC (nulls last), then review count DESC (nulls last), then platform id, then name; take Top 20。

分平台页不重新排名，只把同一份 20 款按店铺分组。括号里的数量是进入综合榜的款数，不是该店榜单的全部长度。

局限与免责

下面这些限制对每一期都成立。读某一期之前，先看该期 JSON 里的 sources_skipped、omissions 和 seed。

  • 这不是全网销量，也不是淘宝、天猫或 Amazon 的官方总榜。
  • 只保留抓取时能打开、并且有商品链接的条目。没有链接的展示（例如 2026-10-16 日榜里 Lovense 首页轮播的 Lush 4 / Lush Mini）记在 omissions，不进 Top 20。
  • 价格、库存、折扣和名次都会变。标成 “As low as” 的数字是该页展示的起步价。
  • 若周榜 JSON 带有 seed，它是某一天日榜的副本，不是单独统计的一周销量。2026-W42 没有 seed：它由 2026-10-15、2026-10-16、2026-10-17 与 2026-10-18 三份日榜汇总。只有一份日榜的周，仍可能是 seed。
  • 外链使用 nofollow。本站不收款、不发货、不提供医疗或健康建议，也不代替你决定买不买。
